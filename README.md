# Indeks żywności — Kogucia Łączka

Otwarty i audytowalny indeks gęstości
odżywczej oraz ekonomicznej żywności.

## Status

Projekt znajduje się w fazie budowy silnika 2.0.

Wyniki nie są jeszcze publikowane jako ostateczne.

## Zasady

- jawna metodologia,
- pełny rozkład punktów,
- rozróżnienie zera i braku danych,
- oddzielenie wartości odżywczej od ceny,
- źródło każdej wartości,
- automatyczne testy przed publikacją,
- brak publikowania niepełnych danych
  jako pełnych wyników.

## Źródła

Podstawowym źródłem danych odżywczych jest
USDA FoodData Central.

## Odpowiedzialność

Indeks ma charakter edukacyjny i analityczny.
Nie stanowi diagnozy ani indywidualnego
zalecenia medycznego.
